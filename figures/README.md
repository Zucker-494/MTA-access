# JTG figure set

This directory contains the figure files used by the current Journal of Transport Geography working manuscript.

## Main-text figures

1. `fig1_spatial.png` — station-complex chronicity and denominator-induced reclassification.
2. `fig2_metric_gap.png` — annual reported availability versus calendar service continuity.
3. `fig3_reclassification.png` — station-complex bottom-quartile recurrence under the two metrics.
4. `fig4_persistence.png` — adjacent-year persistence of station-complex reliability rankings.
5. `fig5_validation.png` — asset-level availability versus official accessible-platform availability.

## Supplementary figures

- `figS1_management_availability.png` — descriptive annual trend by maintenance governance.
- `figS2_borough_metric_gap.png` — borough-level evolution of the denominator gap.

All seven files are PNG outputs at 300 dpi. They are generated by `src/make_figures.py` from the frozen 2026-11-16 MTA analysis snapshot and are now stored directly in this repository.

The spatial map includes borough boundaries for orientation, a north arrow, a 5 km scale bar, and a legend. Figure captions for the manuscript are maintained in `manuscript/figure_captions.txt`.

The GitHub Actions workflow is manual-only. It is used only for deliberate reproduction checks after local validation; ordinary manuscript or code commits do not trigger Actions.
